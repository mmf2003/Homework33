# Gulp Homework

Простий навчальний веб-проєкт для демонстрації роботи з Gulp.

## Можливості

- компіляція SCSS у CSS;
- використання SCSS-змінних та вкладеності;
- автоматичне додавання вендорних префіксів;
- створення читабельного CSS;
- мінімізація CSS;
- автоматичне оновлення сторінки через BrowserSync.

## Використані технології

- HTML
- SCSS
- Gulp
- Sass
- Autoprefixer
- BrowserSync
- Clean CSS

## Встановлення

```bash
npm install
```

## Запуск проєкту

```bash
npm run dev
```

Після запуску відкриється локальний сервер BrowserSync.

## Компіляція стилів

```bash
npm run build
```

Після виконання команди у папці `css` створюються два файли:

- `style.css` — читабельна версія стилів;
- `style.min.css` — мінімізована версія стилів.
